# Planify
App web frontend para explorar países, ver el clima, guardar favoritos y planificar viajes.

## APIs
- REST Countries: países, banderas, capitales, idiomas, monedas.
- Open-Meteo: clima actual y pronóstico de 5 días.
- Nominatim (OpenStreetMap): coordenadas de respaldo si la API de países no las trae.

## Estructura
- `index.html`: estructura y secciones.
- `style.css`: estilos responsive.
- `app.js`: consumo de APIs, filtros, favoritos, formulario, itinerario y localStorage.

## Cómo ejecutarlo
Abre `index.html` en el navegador (necesita internet).
