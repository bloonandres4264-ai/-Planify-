# Planify
Aplicación web frontend para explorar países, consultar el clima en tiempo real, guardar destinos favoritos y planificar itinerarios de viaje.

**Integrantes:** Andrés Bloon, Jonny Cueto, David SanJuan, Anghelo Mendoza 
**Web desplegada:** https://bloonandres4264-ai.github.io/-Planify-/

## APIs utilizadas
- **REST Countries:** consulta de países, banderas, capitales, regiones, población, idiomas y monedas.
- **Open-Meteo:** clima actual y pronóstico meteorológico a 5 días.
- **Nominatim (OpenStreetMap):** geocodificación de respaldo para obtener coordenadas de capitales.

## Estructura del proyecto
- `index.html`: estructura semántica y secciones de navegación.
- `style.css`: hoja de estilos adaptable (responsive).
- `app.js`: consumo de APIs, filtros, gestión de favoritos, validación de formularios y persistencia con `localStorage`.

## Ejecución
Abrir `index.html` en cualquier navegador web moderno con conexión a internet.
